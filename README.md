# My Text Manipulation App

This is a React application built with Vite, TailwindCSS, and Shadcn/UI. It provides various text manipulation functionalities.

## Features

- Convert text to Uppercase
- Convert text to Lowercase
- Copy text to Clipboard
- Clear text
- Capitalize first letter of each sentence
- Reverse text
- Speak text (text-to-speech)
- Download text as a file
- Extract Emails
- Remove Extra Spaces
- Word/Character Count
- Convert to Title Case
- Convert to Alternating Case
- Convert to Sentence Case
- Convert to Kebab Case
- Convert to Snake Case
- Convert to Camel Case
- Convert to Pascal Case
- Reverse String
- Reverse Words
- Remove Numbers
- Remove Special Characters
- Remove Blank Lines
- Convert to Markdown
- Convert to HTML

## Installation

To set up the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   cd my-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in development mode.
Open [http://localhost:5174](http://localhost:5174) to view it in your browser.

The page will reload when you make changes.
You may also see any lint errors in the console.

### `npm run build`

Builds the app for production to the `dist` folder.
It correctly bundles React in production mode and optimizes the build for the best performance.

The build is minified and the filenames include the hashes.
Your app is ready to be deployed!

### `npm run preview`

Serves the `dist` folder locally for production testing.
